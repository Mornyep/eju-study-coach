# 综合科目：知识、材料和历史语境

知识域包括政治・经济・社会、地理、历史。已分析材料既有概念陈述选择，也有地图、条形图、指数表、贸易表和情境材料；不要只刷名词卡。

## 默认以完整 EJU 原题训练

普通“开始综合科目”先选已核对且原页齐全的 EJU 原题，地图、统计图、坐标图必须实际展示。原创用于卡点补练、对比或迁移，调用 supplement 前写明依据；基础比例、四则运算及术语卡仅用于已发现的具体卡点。详见[原题与图片规则](question-images.md)和[原创题型规则](exam-aligned-originals.md)。

EJU 综合科目也有直接知识辨认题和计算题；不要把“题目较短/含计算”一律判为不像 EJU，也不要强迫每题加入表格或多步推理。关键是实际参考的真题任务、学科判断、设问方向与选项区分是否一致。

## 每题先做四件事

1. 识别设问方向：“正しい / 適当でない / 最も適当”等。
2. 标出材料的时间、地区、统计口径、百分比/绝对量、指数基期、图例。
3. 分开“材料直接给出的证据”和“需要调用的知识”。
4. 核对选项是否偷换时间、主体、分母、因果或制度。

| 表现 | 有区分力的训练 |
|---|---|
| 记得名词但选错 | 用两个相近概念解释同一具体情境，并指出区别 |
| 知道制度却读表错 | 隐去国家名，先只读轴、单位和比例；再加入背景 |
| 把比例当总量 | 同时给总量与占比，计算实际量；说明缺少总量时不能推断 |
| 历史顺序混乱 | 3–5 事件排序 → 标必要前因 → 区分同时与因果 |
| 地理无法定位 | 地图位置/气候/资源/产业相互对应，必要时逐层加信息 |
| 老题套当前常识 | 按题目年份作答，另开“今日情况”栏，不替换旧题数据 |

综合题的每个选项可用“结论—材料证据—所需知识”三列检查。不要凭国家刻板印象或近期新闻猜表格。

主动回忆卡应问关系或区分，例如“某政策如何影响需求，成立需要哪些条件”，而不只问名词定义。
涉及今天仍变化的政策/机构/数字时，应核验当前官方来源；无法联网就保留题面年份，不装作已更新。

如果用户要整卷模拟，使用已核实完整材料；自编短练明确标“原创”，列出本次覆盖点和没覆盖的领域。

## 索引中的多知识题

同一国家情境可以串接政治制度、殖民史、地图和贸易数据。目录的一行可有多个标签；不要把每个标签都算该学生的知识缺口。保留共同材料页，先区分题内给定信息与必须回忆的知识。

数量、占比、增长率、指数、余额与累计量分别设对照题；资料缺少总量时不从占比推出绝对量。政治制度、国际组织成员和经济统计须使用该题年份；对今日情况的解释单独核验，不能静默改写旧题。`I.data_methods` 可和其他领域标签交叉筛选，但目录条数不作考频。


## Beta 3 答后复盘

14道官方题提供设问目标、依据、相关知识、选项核对和下一步练习。先追问最早无法解释的位置，再区分知识、图表、时间地点、计算或选项排除；“还不确定”也是有效自述。复盘只保存学习者解释，不能由勾选标签直接推断已掌握或批量生成缺口。
