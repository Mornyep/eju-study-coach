# 新内容预习与薄弱点复习

预习、修复与复测各有目的。开始时只说明今天要建立的一个能力，不一次铺满整章。

## 新内容预习

1. **定义小目标**：例如“能从相邻两项看出公差”，而非“掌握数列”。目标在所选课程内；用户有教材时沿其章节，未知处标待核。
2. **检查必要前置**：用1–2个极短问题，或复用有效记录，每次一问。已提供明确缺口则直接补，不再考全部基础。
3. **建立概念**：用直观例子说明对象、关系、适用条件，再给必要符号和考试日语。不只列公式。
4. **一个完整例题**：解释每步为什么做。用户想先尝试时可先试；已见答案的例题不计独立测试。
5. **一次小验证**：解释关系、辨别反例或一道短新题，方式要匹配目标。只看过写“已接触”；提示后正确写“待独立验证”。
6. **安排接续**：独立小验证通过才建立对应范围的复测基线；仅完成讲解则安排“下次初检”。不把整章标为掌握。

前置不够时，先补一个关键前置，给新内容轮廓并缩小本次目标。不要一次展开所有先修课程，也不要要求“先学完代数再回来”。

数学/物理注意量、图、式的关系；化学注意条件和守恒；生物/综合注意因果、对照和材料年份；日语用短篇章中的表达功能，避免脱离语境的词汇堆。无真实音频时可做文字与图表准备并标边界，不记听力测验通过。

## 薄弱点复习

按“已有观察 → 暂定原因 → 一个对照验证 → 相应训练”进行。索引只帮找材料，不能证明学习者确有该错因。

|已有表现|下一步验证/训练|
|---|---|
|日文条件读错，简单概念题能做|换一题核对否定/范围；区分读题与概念|
|公式记住，不知何时可用|正例与不满足条件的反例，要求选择理由|
|会算，不会文字转式子|列量、目标和关系，逐步撤去提示|
|同题正确，换图不会|图/表/式转换，再做未见题|
|独立思路正确，某步符号错|短练错误步骤，再嵌回完整题|
|不限时能做，限时失误|仅在可靠计时下分析；没有计时先建基线|

一次聚焦一个原因；假设被反例推翻就更新，不强行维持弱项标签。解完原错题只是修复过程，之后需未见独立题与延迟复测。

## 修复何时结束

当场独立新题通过即可结束本次，不无限加题。可用“两道不同情境H0新题＋一次延迟混合复测”作为较保守的稳定性检查；它是教学规则，不是测得的掌握率，不必全挤在同一天。

基础未建立时先同类集中练；方法建立后再交错，标题不泄露解法。复测按 [间隔规则](spaced-retest.md)，题源、提示和答案污染按 [学习记录](progress.md) 保留。
