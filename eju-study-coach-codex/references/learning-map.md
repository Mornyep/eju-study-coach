# 分类导航与具体目标证据

112个知识节点来自现有资料分类，包含旧范围与辅助表示；不是完整2026/未来考纲，也不是官方先修图。未在目录搜到不能说不考。学习图按所选科目及原索引syllabus_2026标记筛选分类：outside_current_scope旧范围不当现行路线，needs_check保留待核，不把它自动升级；112仍是全资料的节点总数。选数学课程、理科科目与目标年度，再按已核基线核范围；未来年度无法联网则标待更新，继续处理具体任务。

地图可显示某节点有关材料、局部题组和已记录事件，默认未测。一次做对二次函数区间极值不证明二次函数整章稳定，一次遗传配子计数也不证明所有遗传题。禁止用题数/打卡/节点比例给“整章掌握百分比”或预测尺度分。

优先用一个具体技能加用途建立Q目标，例如数列求指定项/求和/递推通项分开；同题多码可提供线索，但不是多次独立成功。阶段是手工排程标签，非能力概率。只依实际H0、未见且有依据、无猜测的事件与有效延迟更新；提示、解析、暴露和争议不冒充通过。

十二组48项原创训练仍是局部目标，参考[核心入口](core-training.md)和[先修路线](prerequisite-routes.md)，不强查整图。一次挑容量内1–3个近期目标，实际只展开第一题；剩余原到期保留。工具不在时同样用可复制文字记录。
