# 潜在错因 → 对照验证 → 训练

下列是由题目要求归纳的常见失误机制，不是学生错误率调查。看到索引标签只能提出假设；确定当前优先项需要学习者的首次答案和理由。标签可并存，但一轮先修最早、影响最大的一个卡点。

|代码|先检查的证据|可区分的短验证|对应修正|
|---|---|---|---|
|E.language_condition|是否漏掉否定、量词、例外或“最初/最终”|不解题，复述限制；再用相同难度的新日文条件|条件分层 → 正反例 → 新题|
|E.knowledge|定义、公式或适用条件是否确实缺失|问适用/不适用例，各一个|一句定义＋完整例题 → 补一步 → 独立题|
|E.strategy|会局部运算但起式或模型选择失败|只选系统、变量、定理并说明触发条件|已知/目标/约束 → 比较两法 → 新情境|
|E.representation|图、表、式、文字之间哪一步不一致|同知识换一种表示，运算量相近|双向转换；先读轴、表头、图例和箭头|
|E.calculation|方法正确后的首个符号或算术失误|单独复算局部，改变数值再测|局部练习＋估算/代回，随后嵌回整题|
|E.unit|分母、量纲、比例基数、总量是否偷换|给同占比不同总量，或要求先写单位|标分子分母与基期 → 单位换算 → 材料题|
|E.cases|端点、等号、参数区间是否遗漏|专问临界值、反例和零量情况|列分类依据 → 边界检验 → 完整题|
|E.dependency|后续错误是否都来自同一前空|给正确中间值单测后续步骤|先修根错误；后续只记条件测量结果|
|E.encoding|结果是否正确但栏位/组合行号错误|先报数学值或各陈述真假，再报代码|结果与编码分两栏；核负号/分数外框|
|E.evidence|答案来自原文还是常识/已知结论|要求一个最小依据，指出不能推出什么|主体、范围、程度逐项对应；不可自行补论据|
|E.causality|相关、机制、反向因果和控制变量是否混淆|保持结果改变实验设计，问支持强度|原因→过程→可观察量；比较必要对照|
|E.time_context|历史时点、地区、制度是否被替换|保留原年回答，再独立讨论今天|题面时间轴、事件顺序、版本分栏|
|E.spatial|方向或图上位置是否识别反了|同关系旋转图或更换正方向|标观察方向/坐标，再把空间关系写成式|
|E.sequence|阶段、前后顺序、最终决定是否混淆|给相同节点重新排序并说明依据|过程箭头；将旧提案/修正/决定分开|
|E.audio|是否真的听到、何时丢失信息|需要真实音频，先独立答再回听；看原文后只算复习|声音切分/信息保持/图声对应分别练|
|E.writing|题目必答点与文章实际完成点是否对应|先列任务清单，再检查一段的论据|优先补缺任务 → 论点例证对齐 → 最小语言修改|
|E.material|缺图、裁剪、模糊、省略、答案污染|核原件前后页、出版说明或答案版本|修复/更换材料；不归因于学习者能力|

## 避免重复算错

图像没有看全时，先记材料不足；不要同时“确诊”知识、空间和计算三个缺陷。数学前空错误带来的后继错误、同文多问的共有误读、相同图例导致的多题错答，也先视为可能共享原因。

## 几种跨科对照

- 数学图像与日语听读解图像都可能出现 `E.representation`；前者要测函数关系，后者还需实际录音，不能共享同一种能力结论。
- 综合科目的占比与化学浓度都涉及分母，但学科量不同。会其中一项不证明另一项已掌握。
- 生物实验的“结果支持什么”与日语文章的“作者说什么”都需证据；文章中讲述的研究未必可当作已证实生物知识。
- 时间不足是学习情境变量，本索引不凭题型认定速度缺陷。有真实计时与非限时对照后，再加入限时训练。
