# 从表现到训练

## 先做少量有区分力的题

已给错题：先看首次思路、首个错误位置和完整题面。
没有错题：用 3–5 个短任务覆盖目标科目的 2–3 个前置节点；每次只呈现一题。
不要用统一 20 题大测验拖延开始，也不要让一两题代表整科。

记录“独立正确 / 独立错误 / 正确但猜测 / 提示后正确 / 已见答案 / 无法判定”，分别统计。自报信心可用低、中、高，不伪装成精确能力概率。

| 暂定原因 | 验证问题或对照 | 对应训练 |
|---|---|---|
| 日语读题 | 先让学习者解释条件；再用同难度不同内容、语言更简单的题对照 | 限定/否定/条件词 → 日语条件改写 → 原语言新题 |
| 概念缺失 | 不计算，问定义适用条件或举反例 | 简短解释 → 完整例题 → 补一处步骤 → 独立题 |
| 策略/建模 | 会局部计算但不会起式；让其列已知与目标 | 文字→图/变量→关系式；比较两种方法的适用条件 |
| 表征转换 | 公式会，图或表不会；保持概念改变表示 | 图、表、式、文字之间双向转换 |
| 运算/单位 | 方法正确，某步符号、分母、量纲错误 | 只练错误步骤 → 估算/量纲校验 → 嵌回完整题 |
| 时间分配 | 有可靠用时；非限时能做，限时失误 | 建立基线 → 小组限时 → 跳题与回收顺序 |
| 涂卡/编号 | 数学值正确但填空位置、符号或组合编号错 | 值→栏位映射、连续编号检查；与概念错误分开 |
| 资料问题 | 题面缺图、扫描模糊、答案冲突 | 修复材料或换题；不归责学习者 |

## 避免误诊

- 同一题翻译成中文后答对，可能来自重复接触；把日语障碍当“候选原因”，再给新题验证。
- 两个对照题难度、运算量、前置知识尽量接近；如果不可比，明确说只能提供线索。
- 数学连续空栏的后续错误可能由第一步传播。先定位根错误；可给正确中间量单测后续技能，但这次是有条件测量，不能算整题独立正确。
- 一道选择题猜对后，要求一条关键依据或排除一个干扰项；无需每题解释全部选项。
- 科学或综合题的日语困难，不自动解释为该学科知识不会。
- 没有音频、计时或标准答案时，分别标明缺口，不填想象中的数据。

## 选择训练强度

有前置缺口：先单类型，例题和练习交替；提示逐步减少。
会做但不稳定：混入易混方法，不在标题里提示解法。
稳定但慢：先确认计时可靠和题目难度，再练小题组与检查流程。
距离考试很近：优先处理已证实且可修复的错因、涂卡与时间分配；不宣称“押题”。

可以把“两个不同情境的无提示新题正确，再通过一次延迟混合复测”作为本教练的保守升级门槛。这是工作规则，不是科学测得的掌握率。未复测写“当场通过，保持情况待验证”。

## 一次 25 分钟的可调整样例

3 分钟回忆旧错点 → 5 分钟独立题 → 7 分钟针对讲解与例题 → 7 分钟新题 → 3 分钟记录。此例已用满25分钟；需要缓冲时缩减题量，详见 [日程规划](study-planning.md)。
这是可调整安排；学生只有 10 分钟时，做“一题＋一句错因＋一次后续复测”即可。

## 回合输出示例

“你能列出全部组合，但条件概率的分母仍用了全部结果。本题支持‘条件筛选不稳’这个假设；还不能说明概率整章都不会。下一题先只判断哪些结果仍属于样本空间。”

避免：“你概率基础很差，先重学全章。”


日程/复测/中断规则以 [日程规划](study-planning.md)、[间隔复测](spaced-retest.md) 和 [启动与恢复](restart-support.md) 为准，不能用本节示例固定每天负担。
