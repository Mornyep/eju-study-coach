## CG-JR-F · 基础

次の文章を読んで、本文に合うものを一つ選んでください。
図書館は平日、午後八時まで開いている。ただし、資料の貸出しは午後七時で終わる。午後七時以降も館内で本を読むことはできる。
1. 平日は午後七時に閉館する。
2. 午後七時半でも本を借りられる。
3. 平日の午後七時半には館内で読書ができる。
4. 土曜日も午後八時まで開いている。

## CG-JR-C · 易混条件对照

本文に合うものを一つ選んでください。
学習室は予約した学生を優先する。予約していない学生も、空席があれば利用できる。ただし、午後六時以降は、空席があっても予約が必要である。
1. 予約しなかった学生は一日中利用できない。
2. 午後五時には、空席があれば予約なしでも利用できる。
3. 午後七時も、空席があれば予約はいらない。
4. 予約した学生は必ず午後六時までに退室する。

## CG-JR-T · 迁移

本文の筆者の考えに最も近いものを一つ選んでください。
授業の録画は欠席した学生に役立つ。しかし、録画を見るだけで質問がすべて解決するとは限らない。録画の提供に加え、質問できる時間を設けてこそ、学習を支える仕組みになる。
1. 録画は学生の学習に役立たない。
2. 質問できる時間があれば録画は不要だ。
3. 欠席した学生の質問は録画ですべて解決する。
4. 録画の提供と質問の機会を組み合わせることが大切だ。

## CG-JR-D · 延迟复测

本文に合うものを一つ選んでください。
市は公園にベンチを増やした。その後、公園で休む人は増えたが、散歩する人の数はほとんど変わらなかった。担当者は、この結果だけから公園全体の利用者が増えたとは言い切れないと述べている。同じ人が散歩の途中で休むようになった可能性もあるからだ。
1. ベンチを増やせば、どの公園でも利用者が増える。
2. 散歩する人は大幅に減った。
3. 休む人の増加だけでは、利用者全体の増加を断定できない。
4. 公園で休む人は全員、以前は公園に来なかった人だ。
