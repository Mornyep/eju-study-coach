# 审题、理由与反方处理 · 教练解析

作答前不向学习者展示。候选错因不是学生事实；同组四题各有用途，通过某题仅支持其中实际检验的小目标。

## CG-JW-F

答案/评价要求：开放任务；四句分别完成A利点、B利点、立场、支持该立场的理由。允许任一立场。

先圈出“それぞれ”，保留两个对象。示例方向：当堂共享疑问、课后更有时间说明；立场与理由需匹配。无需把每种方法的缺点都硬塞入，也不把示例视为唯一观点。

核查：
1. 四个可观察要求逐项核对；不按赞同哪种方法判分。
2. 仅为写作准备练习，不称完整EJU作文或官方等级评定。

候选错因：1. E.language_condition
2. E.evidence。

## CG-JW-C

答案/评价要求：所选一方的缺点；依据是「あなたが選ぶ一方の利点と欠点」。

题目这次要求所选一方的利弊，不是双方各自的优点。先确定所选一方，再补其缺点及如何权衡；另一方的缺点并非题目强制。题目未提供实际作文，不能断言字数或语言已经合格。

核查：
1. 与F的对照点为双方利点→一方利弊。
2. 没有完整作文，不生成虚假字数和评分。

候选错因：1. E.language_condition
2. E.evidence。

## CG-JW-T

答案/评价要求：开放任务；双方利点、明确立场、理由（例子可选，不是强制）、400–500字。任一立场或有条件选择均可。

反馈顺序：先检查任务四要求，再找论证中最影响说服力的一处，最后修正少量语言。示例方向仅供作答后讨论：固定成员协作熟悉，更换成员接触不同意见。没有证据不编个人经历；不套用固定段数。

核查：
1. 评价要求均来自原创题干，400–500字只是本练习明确约束。
2. 字数须实际数；无可靠计数写待核；不换算官方分数。

候选错因：1. E.language_condition
2. E.evidence
3. E.knowledge。

## CG-JW-D

答案/评价要求：开放任务；讨论两类空间的作用，明确哪方更大或合理有条件分配，并说明理由；400–500字。

这是新主题的延迟写作，不先展示T的模板。可支持安静空间更大或讨论空间更大，须回应有限面积这一限制。若主张分时复用，仍需交代如何回应面积分配，不绕开设问。

核查：
1. 两类场所功能不能漏一类；不强迫赞成预设方案。
2. 完整作文各维度单独记录；一项通过不升级整个写作能力。

候选错因：1. E.language_condition
2. E.evidence。
